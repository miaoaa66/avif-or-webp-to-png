# AVIF/WebP 转 PNG





预览图   

![preview](./static/preview.png)


使用方法：   
克隆项目或下载压缩包到本地后解压；   
双击index.html文件，在浏览器打开网页；   
点击或拖拽上传 AVIF 或 WebP 格式图片；   
选择目标格式（PNG、JPG、JPEG）；   
系统自动转换并显示下载按钮；   
所有转换操作均在浏览器本地完成；
